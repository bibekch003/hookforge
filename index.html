4 · Run the real thing

This page is a snapshot. The app processes your own uploads.

git clone https://github.com/bibekch003/hookforge.git
cd hookforge && pip install -r requirements.txt
python scripts/make_sample_assets.py
uvicorn app.main:app --port 8000
# then open http://127.0.0.1:8000

No local install? Open the repo → Code → Codespaces → Create codespace: the devcontainer installs everything, then run the uvicorn line above. Deployment options are in docs/DEPLOY.md.
